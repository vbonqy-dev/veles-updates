# Veles

Голосовой ассистент для Windows: команды голосом, чат с нейросетью, управление компьютером и музыкой, заметки, напоминания и таймеры.

Все версии и список изменений — на странице [Releases](https://github.com/vbonqy-dev/veles-updates/releases).

## Установка

1. Скачайте и запустите `VelesSetup.exe`.
2. Если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Выберите папку и нажмите «Установить».
4. Войдите в аккаунт или зарегистрируйтесь и активируйте ключ подписки.
5. Пройдите короткую настройку: нейросеть, голос и распознавание речи.

Подробная инструкция и решения частых проблем — в архиве `VelesAI.*.zip` на странице выпуска.

## Требования

- Windows 10 или Windows 11, 64-бит
- Около 300 МБ для программы и 1,5–2,5 ГБ для голоса и распознавания речи (для полного функционирования)
- Аккаунт Veles и ключ подписки
- Видеокарта NVIDIA желательна (от 2 ГБ видеопамяти), но не обязательна
